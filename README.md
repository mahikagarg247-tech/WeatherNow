# WeatherNow


Features:-
Search weather by city name
Displays temperature in Celsius
Shows weather condition (e.g., Clear, Clouds, Rain)
Displays humidity and wind speed
Loading indicator while fetching data
Error handling for invalid city names
Fully responsive design for mobile, tablet, and desktop

Purpose:-
The purpose of this project is to demonstrate API integration, dynamic data rendering, and responsive web design using modern JavaScript.

Project Description:-
SkyCast is a responsive web application that allows users to check real-time weather conditions of any city. The application fetches live weather data from an external API and displays it in a clean and user-friendly interface.

Api link :- https://api.openweathermap.org
